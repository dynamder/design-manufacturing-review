# 第 4 章 带传动与链传动

> **一句话**：带靠摩擦，所以会滑；链靠啮合，所以会抖。
> 带传动的关键词是**打滑、包角、欧拉公式**；链传动的关键词是**多边形效应、链节数、磨损**。

---

## 1 带传动

### 1.1 四种带，先分清

| 类型 | 原理 | 特点 | 场合 |
| --- | --- | --- | --- |
| 平带 | 摩擦 | 简单、允许大中心距、传动比小 | 低速、大中心距 |
| **V 带** | 楔形摩擦 | 承载大、最常用 | 一般机械 |
| 多楔带 | 楔形摩擦 | 柔性好、高速、多轴 | 汽车、机床 |
| 同步带 | 齿形啮合 | 无滑动、传动比准确、不吸振 | 数控、打印机 |

**V 带为什么能扛？** 楔形槽把正压力放大，当量摩擦系数：

$$f_v=\frac{f}{\sin(\varphi/2)}$$

V 带轮槽角 $\varphi\approx40^\circ$，$\sin20^\circ=0.342$，所以 $f_v\approx2.92f$——同样的张紧力，V 带的摩擦力接近平带的 3 倍。

### 1.2 受力：紧边、松边、欧拉公式

带张紧后，工作时一边拉紧（**紧边** $F_1$）、一边放松（**松边** $F_2$）。

**有效拉力**（就是能传递的圆周力）：

$$F_e=F_1-F_2=\frac{1000P}{v}$$

其中 $P$ 单位 kW，$v$ 单位 m/s，$F_e$ 单位 N。

**欧拉公式**（临界状态，柔索摩擦）：

$$\frac{F_1}{F_2}=e^{f\alpha}$$

$\alpha$ 是包角，**必须用弧度**；V 带用 $f_v$。

**力平衡**（忽略离心力）：

$$F_1+F_2=2F_0$$

联立两式，得到**最大有效拉力**：

$$F_{ec}=2F_0\frac{e^{f\alpha}-1}{e^{f\alpha}+1}$$

> 结论：想多传力，三条路——**增大初拉力 $F_0$、增大包角 $\alpha$、增大摩擦系数 $f$**。包角小于 120° 时，先改中心距或加张紧轮。

### 1.3 应力与失效

带在工作时受三种应力：

| 应力 | 公式 | 说明 |
| --- | --- | --- |
| 拉应力 | $\sigma_1=\dfrac{F_1}{A}$，$\sigma_2=\dfrac{F_2}{A}$ | 紧边大于松边 |
| 离心拉应力 | $\sigma_c=\dfrac{qv^2}{A}$ | $q$ 为带单位长度质量；高速时不可忽略 |
| 弯曲应力 | $\sigma_b=\dfrac{2Ey}{d}$ | 带轮越小，弯曲越厉害 |

**最大应力**发生在**紧边刚进入小带轮处**：

$$\sigma_{\max}=\sigma_1+\sigma_{b1}+\sigma_c$$

带绕一圈，弯曲应力交变一次——这就是带的**疲劳**来源。所以小带轮直径不能太小（$d_1\ge d_{\min}$），否则带很快疲劳断裂。

**两种失效**：

1. **打滑**：过载、摩擦不足，带在小轮上全面滑动。应避免（但可起过载保护作用）。
2. **疲劳破坏**：脱层、撕裂、拉断。由弯曲应力和拉应力反复作用引起。

设计准则：**在不打滑的前提下，有足够的疲劳寿命**。

### 1.4 弹性滑动 vs 打滑（必考简答）

| | 弹性滑动 | 打滑 |
| --- | --- | --- |
| 原因 | 紧边、松边弹性变形不同 | 过载，摩擦力不足 |
| 性质 | **不可避免** | 可以避免，也应避免 |
| 发生范围 | 局部、微量 | 全面滑动 |
| 后果 | 传动比不准确（$\varepsilon\approx1\%$–$2\%$） | 带剧烈发热、磨损，传动失效 |

**滑动率**：

$$\varepsilon=\frac{v_1-v_2}{v_1}$$

**传动比**：

$$i=\frac{n_1}{n_2}=\frac{d_2}{d_1(1-\varepsilon)}$$

> 所以带传动的"传动比"不是简单的 $d_2/d_1$；只有同步带才是准确的 $d_2/d_1$。

### 1.5 几何关系

**包角**（小轮）：

$$\alpha_1=180^\circ-\frac{d_2-d_1}{a}\times57.3^\circ$$

大轮包角 $\alpha_2=180^\circ+\dfrac{d_2-d_1}{a}\times57.3^\circ$。V 带要求 $\alpha_1\ge120^\circ$，平带 $\ge150^\circ$。

**带长**：

$$L=2a+\frac{\pi(d_1+d_2)}{2}+\frac{(d_2-d_1)^2}{4a}$$

**中心距**初选：

$$0.7(d_1+d_2)\le a_0\le2(d_1+d_2)$$

**张紧**：调整中心距、张紧轮（放在松边内侧，靠近大轮）。

### 1.6 例题

V 带传动：$d_1=100$ mm，$d_2=400$ mm，$a=600$ mm，$n_1=1450$ rpm，$P=4$ kW，$f_v=0.51$，$\varepsilon=0.01$。

**（1）带速**

$$v=\frac{\pi d_1n_1}{60\times1000}=\frac{\pi\times100\times1450}{60000}=7.59\ \text{m/s}$$

**（2）传动比与大轮转速**

$$i=\frac{d_2}{d_1(1-\varepsilon)}=\frac{400}{100\times0.99}=4.04,\qquad
n_2=\frac{1450}{4.04}=359\ \text{rpm}$$

**（3）小轮包角**

$$\alpha_1=180^\circ-\frac{400-100}{600}\times57.3^\circ=151.4^\circ=2.642\ \text{rad}$$

$\alpha_1>120^\circ$，合格。

**（4）有效拉力**

$$F_e=\frac{1000P}{v}=\frac{1000\times4}{7.59}=527\ \text{N}$$

**（5）紧边、松边、初拉力**

$$e^{f_v\alpha_1}=e^{0.51\times2.642}=e^{1.347}=3.85$$

$$\frac{F_1}{F_2}=3.85,\qquad F_1-F_2=527\ \text{N}$$

解得：

$$F_2=\frac{527}{3.85-1}=185\ \text{N},\qquad F_1=712\ \text{N}$$

$$F_0=\frac{F_1+F_2}{2}=448\ \text{N}$$

## 2 链传动

### 2.1 组成与特点

链传动 = 主动链轮 + 链条 + 从动链轮，靠链节与轮齿**啮合**传力。

| 优点 | 缺点 |
| --- | --- |
| 无弹性滑动，**平均传动比准确** | 瞬时速度波动（多边形效应） |
| 结构紧凑、承载能力大 | 有冲击、噪声 |
| 效率高（0.95–0.98） | 需要润滑、维护 |
| 可在高温、油污环境工作 | 只适合平行轴 |
| 中心距比齿轮大 | 安装精度要求较高 |

### 2.2 运动与传动比

**平均链速**（$p$ 单位 mm，$n$ 单位 rpm）：

$$v=\frac{z_1pn_1}{60\times1000}\ \text{m/s}$$

**平均传动比**：

$$i=\frac{n_1}{n_2}=\frac{z_2}{z_1}$$

> 注意：这是**平均**传动比。瞬时传动比因为多边形效应会周期性波动。

### 2.3 多边形效应（必考简答）

链条在链轮上不是圆弧，而是**正多边形**的一段。链节铰链中心沿多边形边运动，所以：

- 链条瞬时速度 $v$ 忽大忽小（周期为 $360^\circ/z_1$）；
- 瞬时传动比也周期性波动；
- 产生冲击、振动、噪声，齿数越少越严重。

**结论**：

- 小链轮齿数 $z_1\ge17$（常用 19–25），$z_2\le114$（一般不超过 120）；
- 链节数取**偶数**，避免过渡链节（过渡链节强度低）；
- 高速时选小节距、多齿数。

### 2.4 几何计算

**链节数**（以节距为单位）：

$$L_p=\frac{2a}{p}+\frac{z_1+z_2}{2}+\left(\frac{z_2-z_1}{2\pi}\right)^2\frac{p}{a}$$

算出来**圆整为偶数**。

**中心距**（由链节数反算）：

$$a=\frac{p}{4}\left[\left(L_p-\frac{z_1+z_2}{2}\right)
+\sqrt{\left(L_p-\frac{z_1+z_2}{2}\right)^2-8\left(\frac{z_2-z_1}{2\pi}\right)^2}\right]$$

一般取 $a=(30\text{–}50)p$，最大不超过 $80p$。

### 2.5 失效与设计

| 失效 | 场合 | 措施 |
| --- | --- | --- |
| 链板疲劳断裂 | 闭式、高速 | 减小节距、提高制造精度 |
| 滚子/套筒疲劳 | 高速 | 润滑、选高质量链 |
| 销轴与套筒磨损 | **开式、有尘**（主要失效） | 润滑、防尘、张紧适中 |
| 胶合 | 高速重载、润滑不良 | 改善润滑、限制速度 |
| 静强度拉断 | 低速重载、冲击 | 增大链号、减小冲击 |

设计准则：**一般按耐磨（磨损）设计**；高速链按疲劳强度设计。

润滑方式：人工刷油 → 滴油 → 油浴 → 喷油（速度越高，润滑要求越高）。

### 2.6 例题

滚子链：$z_1=19$，$z_2=57$，$p=12.7$ mm，$n_1=1000$ rpm，$a=40p$。

**（1）平均链速**

$$v=\frac{z_1pn_1}{60000}=\frac{19\times12.7\times1000}{60000}=4.02\ \text{m/s}$$

**（2）传动比**

$$i=\frac{57}{19}=3$$

**（3）链节数**

$$a=40p=508\ \text{mm}$$

$$L_p=\frac{2\times508}{12.7}+\frac{19+57}{2}
+\left(\frac{57-19}{2\pi}\right)^2\frac{12.7}{508}=80+38+0.91=118.9$$

圆整为偶数：$L_p=120$。

## 3 带、链、齿轮怎么选

| 项目 | 带传动 | 链传动 | 齿轮传动 |
| --- | --- | --- | --- |
| 传动比准确性 | 普通带不准确，同步带准确 | 平均准确，瞬时波动 | 准确 |
| 缓冲吸振 | 好 | 一般 | 差 |
| 中心距 | 大 | 较大 | 小 |
| 过载保护 | 打滑，有 | 无 | 无 |
| 效率 | 0.90–0.95 | 0.95–0.98 | 0.97–0.99 |
| 环境 | 怕油、怕高温 | 耐油、耐高温 | 需润滑、密封 |
| 噪声 | 小 | 较大 | 小（精度高时） |
| 典型场合 | 电机→减速器、风机 | 输送机、摩托车 | 减速器、机床 |

> 记忆：**带怕油、链怕尘、齿轮怕脏**；带能保命（过载打滑），链能扛（承载大），齿轮能准（传动比准）。

## 4 易错点清单

1. 欧拉公式里的 $\alpha$ 是**弧度**，不是度。
2. V 带用**当量摩擦系数** $f_v\approx2.92f$，别直接代 $f$。
3. $F_e=1000P/v$ 里 $P$ 是 kW、$v$ 是 m/s，别混单位。
4. 弹性滑动**不可避免**，打滑**应避免**，两者不是一回事。
5. 包角算的是**小轮**，不是大轮；小轮包角最小、最容易先打滑。
6. 带传动比要除以 $(1-\varepsilon)$，不是 $d_2/d_1$。
7. 链速公式除以 60000（mm·rpm → m/s），不是 1000。
8. 链节数必须圆整为**偶数**。
9. 链传动是"平均传动比准确"，瞬时传动比有波动。
10. 小链轮齿数少 → 多边形效应严重 → 冲击、磨损、噪声都变大。
