## 一、四杆机构

| 项目 | 公式 |
| --- | --- |
| 自由度 | $F=3n-2P_L-P_H$ |
| 曲柄存在 | $s+l\le p+q$，且最短杆为机架或连架杆 |
| 极限位置 | 曲柄与连杆共线：$AC_1=a+b$，$AC_2=b-a$ |
| 极位夹角 | $\theta=\left|\angle C_1AD-\angle C_2AD\right|$ |
| 行程速比 | $K=\dfrac{180^\circ+\theta}{180^\circ-\theta}$，$\theta=180^\circ\dfrac{K-1}{K+1}$ |
| 传动角 | $\cos\angle BCD=\dfrac{b^2+c^2-BD^2}{2bc}$，取锐角 |
| 最小传动角 | $BD=d-a$ 与 $BD=d+a$ 两处取小 |
| 位置分析 | $BD^2=a^2+d^2-2ad\cos\theta$；$\cos\angle CBD=\dfrac{b^2+BD^2-c^2}{2b\cdot BD}$ |
| 速度 | $\vec v_C=\vec v_B+\vec v_{CB}$，$v=\omega r$，方向 $\perp$ 杆 |
| 急回设计 | $a=\dfrac{AC_2-AC_1}{2}$，$b=\dfrac{AC_1+AC_2}{2}$ |
| Freudenstein | $K_1\cos\varphi-K_2\cos\theta+K_3=\cos(\varphi-\theta)$ |
| 系数 | $K_1=\dfrac{d}{a}$，$K_2=\dfrac{d}{c}$，$K_3=\dfrac{d^2+c^2+a^2-b^2}{2ac}$ |
| 反解 | $d=K_1a$，$c=d/K_2$，$b=\sqrt{a^2+c^2+d^2-2acK_3}$ |

## 二、电机

| 项目 | 公式 |
| --- | --- |
| 反电动势 | $E=k_e\omega$ |
| 电磁转矩 | $T=k_T I$（SI 下 $k_T=k_e$） |
| 电压平衡 | $V=E+IR$ |
| 机械特性 | $T=T_s\left(1-\dfrac{\omega}{\omega_0}\right)$ |
| 空载转速 | $\omega_0=\dfrac{V}{k_e}$ |
| 堵转转矩 | $T_s=\dfrac{k_TV}{R}$ |
| 堵转电流 | $I_s=\dfrac{V}{R}$ |
| 电流 | $I=\dfrac{T}{k_T}$ |
| 功率 | $P_{out}=T\omega$，$P_{in}=VI$ |
| 效率 | $\eta=\dfrac{P_{out}}{P_{in}}=\dfrac{\omega}{\omega_0}$（理想） |
| 最大功率 | $\omega=\omega_0/2$，$T=T_s/2$，$P_{\max}=\dfrac{V^2}{4R}$ |
| 转速换算 | $\omega=\dfrac{2\pi n}{60}$；$T(\text{N·m})=9550\dfrac{P(\text{kW})}{n(\text{rpm})}$ |
| 工作点 | $T_m(\omega)=T_L(\omega)$ |
| 稳定判据 | $\dfrac{dT_L}{d\omega}>\dfrac{dT_m}{d\omega}$ |
| 减速器 | $i=\dfrac{n_m}{n_L}$，$T_L=i\eta_gT_m$，$J_{eq}=J_m+\dfrac{J_L}{i^2}$ |

## 三、齿轮

| 项目 | 公式 |
| --- | --- |
| 模数 | $m=p/\pi=d/z$ |
| 分度圆 | $d=mz$ |
| 齿顶圆 | $d_a=d+2h_a^*m$（正常齿 $h_a^*=1$） |
| 齿根圆 | $d_f=d-2(h_a^*+c^*)m$（$c^*=0.25$） |
| 基圆 | $d_b=d\cos\alpha$ |
| 中心距 | $a=\dfrac{m(z_1+z_2)}{2}$ |
| 正确啮合 | $m_1=m_2$，$\alpha_1=\alpha_2$ |
| 重合度 | $\varepsilon_\alpha=\dfrac{z_1(\tan\alpha_{a1}-\tan\alpha')+z_2(\tan\alpha_{a2}-\tan\alpha')}{2\pi}$ |
| 齿顶压力角 | $\cos\alpha_a=\dfrac{d_b}{d_a}$ |
| 根切 | $z_{\min}=\dfrac{2h_a^*}{\sin^2\alpha}\approx17$ |
| 渐开线函数 | $\operatorname{inv}\alpha=\tan\alpha-\alpha$ |
| 定轴轮系 | $i_{1k}=(-1)^m\dfrac{\prod z_{\text{从}}}{\prod z_{\text{主}}}$ |
| 转化机构 | $i_{1k}^H=\dfrac{n_1-n_H}{n_k-n_H}=(-1)^m\dfrac{\prod z_{\text{从}}}{\prod z_{\text{主}}}$ |
| 行星（齿圈固定） | $i_{1H}=1+\dfrac{z_3}{z_1}$ |
| 行星（太阳固定） | $i_{3H}=1+\dfrac{z_1}{z_3}$ |
| 差动 | $n_1+\dfrac{z_3}{z_1}n_3=\left(1+\dfrac{z_3}{z_1}\right)n_H$ |
| 同心条件 | $z_3=z_1+2z_2$ |
| 装配条件 | $\dfrac{z_1+z_3}{n_p}=$ 整数 |
| 邻接条件 | $(z_1+z_2)\sin\dfrac{\pi}{n_p}>z_2+2h_a^*$ |
| 谐波（刚轮固定） | $i=\dfrac{z_f}{z_g-z_f}=\dfrac{z_f}{2}$，转向相反 |
| 谐波（柔轮固定） | $i=\dfrac{z_g}{2}$，转向相同 |

## 四、带与链

| 项目 | 公式 |
| --- | --- |
| 带速 | $v=\dfrac{\pi d_1n_1}{60\times1000}$ |
| 有效拉力 | $F_e=\dfrac{1000P}{v}$ |
| 欧拉公式 | $\dfrac{F_1}{F_2}=e^{f\alpha}$（$\alpha$ 用弧度） |
| V 带当量摩擦 | $f_v=\dfrac{f}{\sin(\varphi/2)}\approx2.92f$ |
| 最大有效拉力 | $F_{ec}=2F_0\dfrac{e^{f\alpha}-1}{e^{f\alpha}+1}$ |
| 传动比 | $i=\dfrac{n_1}{n_2}=\dfrac{d_2}{d_1(1-\varepsilon)}$ |
| 包角 | $\alpha_1=180^\circ-\dfrac{d_2-d_1}{a}\times57.3^\circ$ |
| 带长 | $L=2a+\dfrac{\pi(d_1+d_2)}{2}+\dfrac{(d_2-d_1)^2}{4a}$ |
| 弯曲/离心应力 | $\sigma_b=\dfrac{2Ey}{d}$，$\sigma_c=\dfrac{qv^2}{A}$ |
| 平均链速 | $v=\dfrac{z_1pn_1}{60\times1000}$ |
| 链传动比 | $i=\dfrac{z_2}{z_1}$ |
| 链节数 | $L_p=\dfrac{2a}{p}+\dfrac{z_1+z_2}{2}+\left(\dfrac{z_2-z_1}{2\pi}\right)^2\dfrac{p}{a}$ |
| 链中心距 | $a=\dfrac{p}{4}\left[\left(L_p-\dfrac{z_1+z_2}{2}\right)+\sqrt{\left(L_p-\dfrac{z_1+z_2}{2}\right)^2-8\left(\dfrac{z_2-z_1}{2\pi}\right)^2}\right]$ |

> 带：$\alpha$ 用弧度、V 带用 $f_v$；链：链节数取偶数、小链轮 $z_1\ge17$。
