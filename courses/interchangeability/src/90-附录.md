## 一、公式汇总（一页速查）

### 尺寸、偏差与公差（第2章）

| 公式 | 含义 |
|---|---|
| $ES = D_{max} - D$，$EI = D_{min} - D$ | 孔上/下偏差 |
| $es = d_{max} - d$，$ei = d_{min} - d$ | 轴上/下偏差 |
| $T_h = \lvert ES-EI \rvert$，$T_s = \lvert es-ei \rvert$ | 孔/轴公差 |
| $X_{max}=ES-ei$，$X_{min}=EI-es$ | 间隙配合 |
| $Y_{max}=EI-es$，$Y_{min}=ES-ei$ | 过盈配合 |
| $T_f = T_h + T_s$ | 配合公差 |
| $i = 0.45\sqrt[3]{D} + 0.001D$（μm） | 标准公差因子（D≤500） |
| $D_j = \sqrt{D_1 D_2}$ | 尺寸分段几何平均 |
| $\Delta = IT_n - IT_{(n-1)}$ | 特殊规则修正量 |

### 测量误差（第3章）

| 公式 | 含义 |
|---|---|
| $\Delta = L - L_0$，$\varepsilon = \dfrac{\Delta}{L_0} \approx \dfrac{\Delta}{L}$ | 绝对/相对误差 |
| $\delta = L\,[\,a_2(t_2-20) - a_1(t_1-20)\,]$ | 温度误差 |
| $\bar L = \dfrac{1}{N}\sum L_i$ | 算术平均值 |
| $v_i = L_i - \bar L$ | 残差 |
| $\sigma = \sqrt{\dfrac{\sum v_i^2}{N-1}}$ | 单次测量标准偏差（贝塞尔） |
| $\sigma_{\bar L} = \dfrac{\sigma}{\sqrt N}$ | 平均值标准偏差 |
| $\Delta_{lim} = \pm 3\sigma_{\bar L}$ | 极限误差；结果 $L_0 = \bar L \pm \Delta_{lim}$ |
| $\lvert v_i \rvert > 3\sigma$ | 拉依达准则（判粗大误差） |

### 公差原则（第4章）

| 公式 | 含义 |
|---|---|
| $D_{fe} = D_a - f_{形位}$，$d_{fe} = d_a + f_{形位}$ | 体外作用尺寸（对配合起作用） |
| $D_{fi} = D_a + f_{形位}$，$d_{fi} = d_a - f_{形位}$ | 体内作用尺寸（对强度起作用） |
| $d_{MV} = d_{max} + t$，$D_{MV} = D_{min} - t$ | 最大实体实效尺寸（Ⓜ） |
| $d_{LV} = d_{min} - t$，$D_{LV} = D_{max} + t$ | 最小实体实效尺寸（Ⓛ） |
| 孔 $D_M=D_{min}$、$D_L=D_{max}$；轴 $d_M=d_{max}$、$d_L=d_{min}$ | 最大/最小实体尺寸 |

### 孔基本偏差换算

| 规则 | 适用 | 公式 |
|---|---|---|
| 通用规则 | 大多数 | $A$~$H$：$EI = -es$；$J$~$ZC$：$ES = -ei$ |
| 特殊规则 | $K$、$M$、$N$（≤IT8）；$P$~$ZC$（≤IT7） | $ES = -ei + \Delta$，$\Delta = IT_n - IT_{(n-1)}$ |
