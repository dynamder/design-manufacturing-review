# 易混辨析（选择题重灾区）

| 易混点 | 区分 |
|---|---|
| 完全 vs 不完全互换 | 完全=不挑不修直接装配；不完全=分组/概率/调整法，放宽公差但降低互换水平 |
| 精密度 vs 正确度 vs 精确度 | 精密度看**随机**误差、正确度看**系统**误差、精确度看**两者综合** |
| 间隙 vs 过渡 vs 过盈 | $X_{min}\ge0$ 间隙；$Y_{max}\le0$ 过盈；$X_{max}>0$ 且 $Y_{max}<0$ 过渡 |
| 基孔制 vs 基轴制 | 基孔制固定孔 H（EI=0）；基轴制固定轴 h（es=0） |
| 直接 vs 间接测量 | 直接=量值直接读出；间接=测别的量再按函数算出 |
| 绝对 vs 相对测量 | 绝对=示值即量值；相对=示值是相对标准量的偏差 |
| 主动 vs 被动测量 | 主动=加工中测（预防废品）；被动=加工后测（剔除废品） |
| 通规 vs 止规 | 通规控作用尺寸（最大实体）；止规控实际尺寸（最小实体）；通规过、止规不过=合格 |
| 独立原则 vs 包容要求 vs 最大实体要求 | 独立=无符号、各自独立；包容=Ⓔ、最大实体边界、保配合；最大实体=Ⓜ、最大实体实效边界、保可装配 |
| 系统 vs 随机 vs 粗大误差 | 系统=不变或按规律变（可消除）；随机=不可预定（只能估算）；粗大=明显歪曲（剔除） |
| 分度值 vs 分辨力 | 分度值=每刻度所代表量值；分辨力=最末一位数所代表量值 |
| 形状 vs 位置公差 | 形状不涉及基准（浮动）；位置相对基准有确定方向/位置 |
