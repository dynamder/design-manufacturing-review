# 第五章 · 一面盾牌

那通电话不是演习。同行的厂子被勒索病毒打了：病毒顺着一台联网的控制器爬进来，锁死了它下游的一切。每一台停机的机器都是"非计划停机"，而在我们那张表上，那是每小时 5000 元、还要复利累加。前四章我们一直在开门——90% 联网率、远程可视、客户现场的 5G、云、平台。现在，我们得建蓝图的第三条腿——安全，而且得在每一扇门都敞着的情况下建。

## 一条穿透墙壁的蠕虫

先搞清楚我们到底在怕什么。2010 年，一条叫**震网病毒**（Stuxnet）的蠕虫做到了此前没人证明过可行的事：它穿过网络，在物理世界里毁掉机器。它的目标是伊朗纳坦兹工厂的铀浓缩离心机。它靠一支 U 盘溜进来，搜寻西门子的控制器，重写了它们的逻辑，让离心机把自己转散架——而操作员的屏幕上，还在重放正常的数字。

最后这一点，才是最要紧的一课。这次攻击不只是闯了进来；它*对盯着屏幕的人撒了谎*。课程称震网为**第一个以工业控制系统为目标的破坏性蠕虫**，也是**历史上第一个攻击现实世界基础设施的蠕虫**。结论就一句话：**网络攻击能在现实世界造成物理破坏。**

它的六步，说明了它为何得手：

1. **感染**——骑着一支 U 盘越过物理隔离，落到一台 Windows 主机上；
2. **扫描**——找出运行西门子软件的工程师站和 PLC；
3. **更新**——向命令服务器"回电"索取新代码，让杀软杀不掉它；
4. **破坏**——把篡改过的逻辑推进 PLC，让离心机跑错；
5. **控制**——隐藏、驻留、把持系统；
6. **欺骗与摧毁**——在机器自我撕裂时，往监视器上重放正常数据。

由此落下三条结论，每一条都改写了一个天真的假设：**物理隔离不等于安全**（那支 U 盘*就是*那个缺口）；**安全机制是薄弱的**（PLC 对控制器告诉它的话照单全收）；**单一防线必然被破**。物理隔离还有两个副作用——补丁进不来，漏洞一开就是好几年；没有监测，出事才知道。

## 五扇门，四层楼

那么我们到底在守什么？不是一样东西——是五样。课程把它们摆成五类并列的安全威胁：**设备、控制、网络、应用、数据**。

| 威胁 | 瞄准的对象 |
| --- | --- |
| **设备** | 车间里的机器人、智能仪表、传感器 |
| **控制** | 控制软件与控制协议 |
| **网络** | 内网、外网及其边界 |
| **应用** | 平台与工业应用 |
| **数据** | 厂内数据、厂外数据、用户信息 |

一次攻击通常一次横跨好几类：震网用的是设备侧的入口（U 盘）、控制侧的武器（篡改逻辑）、数据侧的遮掩（重放的监视画面）。所以这五类不是一张挨个打钩的清单，而是同一块表面的五张面孔。

要组织防御，得画一张网格——安全框架。水平方向，是上面五个域，外加一列**新兴技术**（人工智能、区块链、可信计算、零信任），它不算第六个域，而是一套能伸进任意一个域的工具。垂直方向，四层：**产业层、企业层、工厂层、设备层**。水平说的是*哪一类安全*；垂直说的是*世界在哪一层*。把两者弄混，你就会闹出"在产业层上装防火墙"这种笑话。

现在把五个域挨个走一遍——每一个都以特定方式变了，而每一次变，都是它那扇门被打开的原因。

## 设备：机器学会了思考，所以它现在可以被改写

车间变了。一台机械车床，只能用扳手弄坏它；一台数控车床跑的却是**嵌入式操作系统 + 微处理器 + 应用软件**——它现在是台电脑了，而电脑是可以被改写的。四个后果：攻击**传播快**（一千台机器装同一套固件 = 一个漏洞处处复制）；攻击**直达设备**（跳过它上面的主机）；**波及范围变大**（一台设备拖垮一条线，进而一个厂）；**漏洞影响放大**（从单一型号扩大到成批的通用设备）。

四道防线（设备安全防护）：

- **固件攻击面减少**（FASR）——加固操作系统内核与协议栈。固件（Firmware）是存在*硬件里*的特殊软件，桥接硬件与它上面的操作系统。
- **漏洞修复与补丁管理**——两件活，一个提醒。流程是*检测 → 下载 → 测试 → 批准 → 安装*，而**测试**和**批准**排在**安装**之前，因为在跑着的产线上打一个坏补丁，代价比漏洞本身还大。
- **硬件安全增强**——给硬件一个身份，用安全芯片或安全固件作为**信任根**。
- **运维管控**——管住什么东西能插进来。震网那支 U 盘，正是它要挡的。

## 控制：从一座上了锁的金字塔，到一片开放的工地

控制变得最厉害：它从**分层、封闭、局部**，变成了**扁平、开放、全局**。**IT 与 OT 融合**，控制网络开放，监测往上走、实时控制往下走。老金字塔的中间层原本能把东西隔开；扁平结构把它们拆掉了。

这是安全与"安全"正面相撞的唯一一个域。**信息安全**问的是"系统被攻破了吗？"；**功能安全**问的是"会不会有人受伤？"——而两套防御互相打架：给 PLC 打补丁意味着停线，防火墙增加时延，加密拖慢实时控制。你不能照搬 IT 那套"关掉修一修"；一切都得在线、不中断、可回退。

协议这一侧，五道防线（控制协议安全）：**身份认证**（知识类认证——"你知道什么"，资产类认证——"你有什么"，本征类认证——"你是什么"，组合使用）；**白名单**（默认拒绝，只有已知可信的指令才放行）；**访问控制**（证明你是谁之后，再限制你能碰什么）；**传输加密**（在协议栈加安全层、在报文中加安全字段，或收紧会话过程）；**脆弱性测试**（系统性地找出弱点，其中**模糊测试**占 80% 的工作量，因为工业协议是二进制、私有的，只有畸形输入才能探到边界）。

软件这一侧，还有四道：**软件防篡改**、**恶意软件防护**、经典的**补丁**（在线、不中断），以及**安全监测与审计**——它倚重**无监督学习**，因为工厂没有带标签的攻击样本（你不能在活产线上做实验），只有一类"正常"，于是算法学"正常"、标"反常"。

## 外围三环：网络、应用、数据

网络从专有变成了开放——处处 IP、处处无线、IT 与 OT 相接、专网遇上互联网。**专有协议**本身就是一道盾（工具少、专家少）；换成**以太网/IP**，等于把整套 IT 攻击工具包请了进来。五道防线（网络安全防护）：**网络隔离**（物理、协议、应用三档逐步放宽）、**边界管控**（在边界看管与拦截）、**接入管理**（对每台设备、每个标识解析节点做身份认证）、**通信和传输保护**（加密与校验）、**入侵检测系统**（IDS——基于规则抓已知之恶，基于异常、现在还有深度学习抓未知之怪；工业交换机偏弱，几百兆的 **DDoS** 就能把它淹了）。

应用域分成**平台安全**——六项：安全审计、认证授权、安全隔离、安全监测、补丁升级、**DDoS 防护**——和**工业应用程序安全**——五项：代码审计、补丁升级、脆弱性检测、审核测试、行为监测和异常阻止。

数据是"流动"本身变了：它从少量、单一、单向，变成了大量、多维、**双向**。一旦数据越过企业边界，问题就从"会不会泄露"变成"谁在用、在哪用、能不能收回来"。防线跟着数据的位置走：**传输中，加密；处理中，识别敏感性、授权、脱敏；存储中，访问控制加加密**。在此之上，还有四样新兴工具：**人工智能**（识别、追踪、告警、管控）、**区块链**（可信的存储与交换）、**可信计算**（硬件 + 软件，保证系统如预期运行）、**零信任**（"永不信任，始终验证"：对内网也不给默认信任）。

## 墙那边的账本

有一样新兴工具值得单独一看，因为它解决了一个别人解决不了的问题。跨企业协作没有共同的信任中心——这正是数据共享难的全部原因。**区块链**是一种**由区块组成的链式结构**：一个**去中心化的、不可篡改的分布式账本**。五个特性：透明、不可篡改（哈希链）、去中心化、可追溯、交易成本更低。在工业里，它意味着没有任何一方独享记录，而每一条记录都能审计回溯到源头。

工业区块链的四个特征排成一条链——技术基础（数字签名、时间戳、分布式共识、智能合约）→ 功能优势（多方信任、跨组织协作、可控共享、可审计防篡改）→ 应用领域（可信存证、全流程追溯、资产监管）→ 结论：**区块链与工业互联网必须协同演进**（链网协同）。

四桩工业痛点，四个区块链答案：

| 痛点 | 区块链解法 |
| --- | --- |
| 信任难建立 | **分布式信任管理**——为人、机、物建立联邦式数字身份 |
| 数据确权难 | **数据确权流转管理**——把每份资产绑定到账本上的身份标签 |
| 数据安全共享难 | **数据安全共享管理**——同态加密让模型流转、原始数据不动 |
| 事后审计难 | **事件审计追溯管理**——每个事件上链，可审计回溯到源头 |

共享方案里那句好记的话：*模型走、数据不走*（数据模型共享、数据不可见）。

## 收个尾

五个域，各自在各自层面设防，区块链补上跨企业那个缺口。盾立起来了：设备加固、控制认证、网络隔离与监测、应用与数据设防。蓝图的第三条腿，站住了。

而现在，这一整段苦旅里，我们第一次可以停下建设、回头看看了。因为有个问题从最早那次会面起就一路跟着我们，而我们一直用硬件而不是用语言去回答它。采购问"你们的机床支持工业互联网吗？"我们说"它带 4G 模块"，他说*那不算*。我们花了五章建出来的这玩意儿，到底*是什么*？它叫什么、为的是什么？那是最后一章。
