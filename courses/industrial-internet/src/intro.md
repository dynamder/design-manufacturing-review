# 使用说明：按官方课件第 1–6 章组织的复习资料

## 0 这份材料是什么

- **依据**：本课程六章官方课件（李照东、雷祎凤、葛东升，《工业互联网基础》，动力与机械学院）。
  全六章课件共 **510 页**（另有 1 讲 51 页的企业讲座），本资料逐章读过并做了结构化重写，
  **没有引用任何课件之外的教材结论**；偶有课件未讲、但论述题会用到的常识，一律标【补充】。
- **面向题型**：期末为**选择、填空、论述**三类。因此本资料的重点不是推导，而是
  ①**术语的准确定义**（选择、填空直接考）；②**清单类知识的完整枚举**（"三大体系""五类
  威胁""四个层次"，填空和选择的高频点）；③**因果链与对比**（论述题的骨架）。
- **依据的"第二手信号"**：每章课件最后一页的**课后习题**。那是老师亲手列的题，
  论述题几乎都从里面变形出来。本资料每章末尾都列出该章课后习题的"答题落点"。
- **插图**：直接从课件 PDF 抽的 25 张关键图（架构图、功能视图、TSN 原理、CPS 三级模型……），
  图注里标了**出自第几章第几页**，等于把 PPT 搬到了正文旁边。

## 3 三条主线（先建框架，再背细节）

把六章压成三条线，考场上任何一道论述题都能挂到其中一条上：

1. **"它是什么、和谁不一样"**（第 1 章 + 第 3 章）
   工业互联网 = 新一代信息通信技术与工业经济深度融合的**新型基础设施、应用模式和工业生态**
   （【课件 C1·P18】）。三大体系 **网络是基础、平台是核心、安全是保障**（【课件 C1·P21】）。
   → 一切论述题的"总纲"就是这三句话，先写它，再往下一层层展开。

2. **"数据怎么从设备走到决策"**（第 2、4、5 章）
   现场设备 →（协议/网关/标识解析）→ 工厂内网 → 工厂外网 → 平台（边缘/PaaS/应用）
   → 模型 → 服务。这条链上每一环都有一组术语和一组清单（协议名、层级名、平台名）。

3. **"放开之后怎么不出事"**（第 6 章）
   设备、控制、网络、应用、数据**五个维度**各有"变化 → 风险 → 防护技术"三段式。
   论述题的模板就是这五段各写两行，再补一句"零信任/区块链/可信计算"收尾。

## 5 应试技巧（选择/填空/论述各一组）

### 选择（占比最高，但要"快准"）

1. **先辨"层级错位"**：选项把"网络层"的功能安到"应用层"上，是最常见的干扰项。
   遇到层级题，先在草稿上写 4 层 / 3 层列表，再逐项对号。
2. **警惕"绝对化"**：出现"完全""唯一""不需要""彻底替代"的选项，八成错。
   课件里确实有"唯一"的地方（EtherNet/IP 是**唯一**完全基于以太网标准的工业以太网协议，
   【课件 C2·P37】），这类"课件原话里的唯一"才是正确选项。
3. **数字题只考课件里出现过的数字**：5G 的 1 ms / 99.9999% / 1 台·km⁻²/1 Gbit/s / 1 μs；
   UWB 0.1–0.5 m；安贝格 99.9985%；波音 10%；小卫星 −75%。记不全就记"量级"。

### 填空（一分不能丢，考的是"原词"）

1. **写全称而不是简称**：题目给"（ ）"时，按课件写法填——"分布式控制系统（DCS）"
   比只写"DCS"稳。
2. **成组记忆**：凡是"三大/五大/六大"，一定连着序号背，因为填空常挖其中一格。
3. **不要自创词**：把"泛在连接"写成"无处不在的连接"、把"标识解析"写成"标识解码"都是 0 分。

### 论述（决定成败，考的是"结构"）

1. **开头一句定性**：先给定义或总纲（"工业互联网是……的新型基础设施、应用模式和工业生态"）。
2. **中间分点，点数与题目分值匹配**：10 分的题写 4–5 点，每点"术语 + 一句解释 + 一个例子"。
3. **每点尽量带课件里的专有名词**（网络互联/数据互通/标识解析、单元级/系统级/SoS 级、
   设备/控制/网络/应用/数据），阅卷老师找的就是这些词。
4. **结尾一句"落回工业"**：说明它解决了什么问题（降本、增效、提质、安全），
   这句话几乎是所有论述题的通用收尾。
5. **时间分配**：论述 50 分 ≈ 50 分钟，每题 10 分钟：2 分钟列提纲、7 分钟写、1 分钟补术语。

## 6 常见问题

**Q：课件里的视频链接、企业广告页要看吗？**
A：不看。课件里嵌了十几个 B 站视频（【课件 C4·P15/21/37/53...】），考不了；
但视频所在页的**文字结论**要看，那才是考点。

**Q：第 5 章 165 页，太多了，能不能只背重点？**
A：可以，但要知道"重点在哪"。第 5 章真正的必考点只有五处：平台的**四层架构与本质**、
**CPS 三级**、**工业大数据特征**、**数字孪生三特征**、**三个应用方向 + 案例数字**。
其余（传感器原理、RFID 近场远场、可视化分支）只出选择填空，看 `cheatsheet` 就够。

**Q：课件里的英文术语怎么处理？**
A：选择填空常给中文问英文缩写，或反过来。`cheatsheet` §1 有完整中英对照表，
至少把 40 个缩写（IoT/IIoT/CPS/MES/ERP/SCADA/DCS/PLC/TSN/LPWAN/NB-IoT/OPC UA/MQTT…）背下来。

**Q：实验课（PLC）和这门课什么关系？**
A：实验做的 PLC 基础操作、流水线控制、PLC 网页交互，对应的理论就是 `ch05` §4 的
PLC 循环扫描原理与"PLC = 单元级 CPS"。论述题若问"为什么说 PLC 是单元级 CPS"，
答"它能独立完成感知—计算—控制的小闭环"，见 `ch05` §4.2。

**Q：附录里的"工业互联网框架图"是什么？**
A：那是按本课程四层（SaaS/PaaS/IaaS/边缘）画的一张 A4 手绘图，用来在考场上快速
画出"分层 + 协议 + 安全"的整体图。画法见 `appendix` §3。
