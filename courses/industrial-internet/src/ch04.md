## 1 工业互联网标识（4.1）

### 1.1 从身份证到标识：三个类比

> 【课件 C4·P6】<strong>定义</strong>：工业互联网标识是一种<strong>标识化系统</strong>，通过<strong>数字化、编码或其他形式
> 的唯一识别符号</strong>，为工业物品、设备、产品等实体赋予独特的标识符号，使其能够在互联网环境中
> 被<strong>唯一识别、定位和管理</strong>。

<strong>标识与域名的对照</strong>（【课件 C4·P6】，这张表把"标识解析"和"DNS"讲透了）：

| 对比项 | 互联网计算机标识 | 工业互联网标识 |
| --- | --- | --- |
| 名字 | 域名：`www.baidu.com` | 标识：`86.10000/ac.qd.1024` |
| 结构 | — | <strong>国家 / 厂商 / 设备 / 城市 / 序列号</strong> |
| 解析系统 | <strong>域名解析系统（DNS）</strong> | <strong>标识解析系统</strong> |
| 解析结果 | IP 地址：`123.125.114.114` | IP 地址：`3ffe:8080::1` <strong>+ 标识关联的信息</strong> |

标识编码 `86.10000/ac.qd.1024` 的五段含义：<strong>国家、厂商、设备、城市、序列号</strong>。

> 【课件 C4·P7】标识解析系统的作用：多个"国家、企业、类别、序列号"各自<strong>唯一对应</strong>一个标识，
> 通过标识解析系统实现<strong>数据互通</strong>与<strong>综合管理</strong>，最终实现工业互联网设备、产品、人员、企业
> 的<strong>高效管控</strong>。

### 1.2 两类标识载体

| 类别 | 载体形式 | 特点 | 优点 | 不足 |
| --- | --- | --- | --- | --- |
| <strong>被动标识载体</strong> | <strong>条形码、二维码、射频识别（RFID）、近场通信（NFC）</strong> | 自身<strong>不带电</strong>，靠外部读写设备"读取" | 成本极低（条码/二维码近乎零成本）、技术成熟、易印刷 | 需外部设备读、<strong>读写距离近</strong>、条码易污损、<strong>不能主动上报</strong> |
| <strong>主动标识载体</strong> | <strong>通用集成电路卡（UICC）、通信模组、芯片（MCU）、终端</strong> | 自带<strong>通信与计算能力</strong>，可主动联网上报 | 可<strong>主动上报</strong>、可远程管理、可承载更多数据 | 成本高、<strong>需要供电</strong>、改造难度大（课件问"哪个更难"） |

主动标识载体为什么比被动标识载体难？ ：三个理由：① <strong>要供电</strong>（现场取电难）；② <strong>要联网</strong>（协议/网络配置复杂）；③ <strong>要安全</strong>（密钥、证书、远程升级都要管）。而被动载体只要"印上去/贴上去"就行。课件 P9 那句"优点和不足？ 哪个更难？ "就是埋的这个点。

RFID 属于<strong>被动标识载体</strong>（课件 P8 明确列在被动里），尽管它"无线"。判断标准是<strong>能不能自己主动发起通信并携带智能</strong>，不是"有没有无线电"。

### 1.3 标识的应用流程与安全体系

> 【课件 C4·P10】应用流程：<strong>产品生产/设备部署 → 标识分配 → 标识解析系统（标识编码生成、
> 标识入库）→ 生产管理 / 状态监控 / 数字化管理</strong>。

> 【课件 C4·P11】标识安全体系（两大部分）：
> - <strong>标识安全性</strong>：加密（<strong>加密传输、加密编码</strong>）、<strong>身份验证</strong>、<strong>访问控制</strong>、<strong>数据备份</strong>、
> <strong>网络安全</strong>；
> - <strong>标识隐私保护</strong>：<strong>数据匿名</strong>、<strong>隐私政策</strong>、<strong>标识生命周期管理</strong>。

### 1.4 标识的作用与六个"一码"

| 提法 | 含义 |
| --- | --- |
| <strong>一码一物</strong> | 一个标识码对应一个产品，扫码解析获得产品全信息 |
| <strong>一码上云</strong> | 一个标识码连接设备上云，实现设备生命周期全监控 |
| <strong>一码全览</strong> | 一个标识码查看所有环节，快速了解产品质量全追溯 |
| <strong>一码协同</strong> | 一个标识码实现协同到底，帮助企业数据共享全打通 |
| <strong>一码分权</strong> | 一个标识码实现多种识别，帮助企业不同对象全管控 |
| <strong>一码万能</strong> | 一个标识码实现万个功能，帮助企业提供产品全服务 |

"<strong>物、云、览、同、权、能</strong>"——一个字对应一个"一码"。

## 2 工业互联网标识解析（4.2）

### 2.1 定义与核心内容

> 【课件 C4·P17】核心内容两部分：<strong>标识编码</strong> + <strong>标识解析</strong>。

解析过程（【课件 C4·P17】的流程图，一段话讲清）：

"标识解析与 DNS 的区别"——三条：① DNS 解析的是<strong>域名→IP</strong>，标识解析是<strong>标识→地址 + 关联信息</strong>；② DNS 是<strong>全球统一</strong>的（ICANN），标识解析是<strong>多根并存</strong>的（Handle/DNS/OID/GS1/DID 各自有根）；③ 标识解析还要解决<strong>跨企业、跨行业、跨地域</strong>的<strong>数据互通与确权</strong>问题，DNS 不管这些。

### 2.2 为什么要推标识解析：五个痛点

| 痛点 | 表现 |
| --- | --- |
| <strong>国家内统一布局缺乏</strong> | 各行业、各地区自建体系，互不相通 |
| <strong>国际上数据安全受威胁</strong> | 根节点在境外，数据主权受制于人 |
| <strong>企业间信息互通困难</strong> | 协作企业之间数据对不上 |
| <strong>企业内数据交流困难</strong> | 历史数据库、SCADA、工业 PC、PLC 各自为政 |
| <strong>工厂内设备标识复杂</strong> | 零部件标识、在制品标识、产品标识各不相同 |

这五条是"为什么要建国家标识解析体系"的标准答案。

<strong>（2）Handle 根体系</strong>

| 缩写 | 含义 |
| --- | --- |
| <strong>GHR</strong> | <strong>国际并联根节点</strong>（Global Handle Registry） |
| <strong>ARS</strong> | <strong>全球辅根节点</strong>（全球所有 Handle 根系统 MPA 之间<strong>平等、协商、共管</strong>） |
| <strong>ARS-MPA</strong> | MPA 辅根节点（国家工业互联网节点、电子政务节点等） |
| <strong>LHS</strong> | <strong>下级授权节点</strong>（行业节点、区域节点、企业节点、N 级节点） |

解析方式（同页）：<strong>缓存/递归解析服务节点</strong>提供<strong>递归解析</strong>与<strong>缓存解析</strong>。

GHR = 国际并联根节点；ARS = 全球辅根节点；LHS = 下级授权节点。Handle 体系的核心理念是"<strong>平等、协商、共管</strong>"，不是"美国主导"。

### 7.1 5G

五类应用（【课件 C4·P62】）：<strong>远程协同管理</strong>（多地远程协同在线研发设计）、<strong>智能化生产</strong>

<strong>5G 的五个关键指标</strong>：

| 指标 | 数值 |
| --- | --- |
| <strong>广连接</strong> | <strong>1 百万 / km²</strong> |

## 本章要点

1. <strong>标识定义</strong>：数字化/编码的唯一识别符号，使实体能被<strong>唯一识别、定位和管理</strong>。
2. <strong>两类载体</strong>：被动（条码、二维码、RFID、NFC）、主动（UICC、通信模组、MCU、终端）。
3. <strong>标识 vs 域名</strong>：标识 = 国家/厂商/设备/城市/序列号；解析返回 <strong>IP + 关联信息</strong>。
4. <strong>六个"一码"</strong>：一码一物、一码上云、一码全览、一码协同、一码分权、一码万能。
5. <strong>标识解析核心内容</strong>：<strong>标识编码 + 标识解析</strong>。
6. <strong>五大痛点</strong>：国家布局缺乏、国际数据安全受威胁、企业间互通难、企业内交流难、工厂内标识复杂。
7. <strong>节点五级</strong>：国际根节点（Handle/DNS/OID-GS1/DID）→ 国家顶级节点（京沪渝穗汉）→ 二级节点
 → 企业节点 → 公共递归节点；<strong>节点是基础、应用是目的、技术是保障</strong>。
8. <strong>功能视图四层</strong>：标识编码层、标识解析层、标识数据层、标识应用层。
9. <strong>Handle 体系</strong>：GHR（国际并联根）、ARS（全球辅根）、LHS（下级授权）。
10. <strong>网络连接三部分</strong>：网络互联、数据互通、标识解析。
11. <strong>工厂内网两层三级</strong>：IT（企业级）/OT（车间级、现场级）；按业务分生产网、办公网、安防网、
 企业数据中心。
12. <strong>工厂外网四专线</strong>：上网专线（OTN/MPLS VPN）、互联专线（SD-WAN）、上云专线（Cloud VPN）、
 上网连接（5G/NB-IoT）。
13. <strong>协议家族</strong>：现场总线 8 个、工业以太网 4 个、工业无线 8 个；异构互通三招（网关/适配器/
 格式转换）。
14. <strong>5G 五指标</strong>：1 百万/km²、1 Gbit/s、1 ms、99.9999%、1 μs；三技术：高频多天线、网络切片、
 边缘计算。
15. <strong>TSN</strong>：IEEE 802.1 增强标准、确定性通信；四问题四机制；<strong>全局时钟 + 传输调度器</strong>。
16. <strong>边缘计算</strong>：四类核心能力、三层功能视图、四大功能（自动控制/分析/优化/感知执行）、
 三大能力（计算/网络/存储）。
