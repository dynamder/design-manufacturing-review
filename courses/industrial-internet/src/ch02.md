# 第 2 章 工业互联网基础技术

> 本章对应课件《第 2 章 工业互联网基础技术》（共 92 页）。
> 图例：加粗 = 课件原文中以红色（深红或纯红）标出的内容，句尾〔标红 C2·Py〕标注来源页。本文不用加粗表达其他强调。

本章讲工业互联网最底层的五组技术，它们串成一条自上而下的支撑链：物联网把万物接进来，网络通信把数据送出去，云计算把算力聚起来，工业大数据把数据用起来，信息安全则保证这一整条链不被攻破。

## 2.1 物联网技术

### 2.1.1 定义与本质

**物联网**（**IoT**）是**物**与**网络**的结合：通过信息传感设备将要连接的物体接入网络，让接入网络的物体实现**互联互通**，并实现对这些物体的识别、控制、管理、定位、互联、信息共享等，推动了信息科学技术产业的**第三次革命**〔标红 C2·P5〕。

它的**本质**仍然是互联网〔标红 C2·P5〕。终端不仅是计算机，还包括通过传感设备连接的其它物体；按照约定的协议和信息安全保障机制，对物体进行在线监测、安全管理、定位追踪、调度指挥、远程控制、在线升级等，实现对万物的管理〔C2·P5〕。

> "本质还是互联网"这句话把很多争论一次关掉：物联网既不是"传感器网"，也不是另造一张新网，它只是把互联网的终端从计算机扩展到物。协议与信息安全保障机制这两件事不变，变的只是"谁在上网"。

### 2.1.2 三个特点：全面感知、可靠传输、智能处理

| 环节 | 定位 | 内容 |
| --- | --- | --- |
| 感知 | 全面感知 | 利用 RFID、传感器、二维码等，随时随地采集物体的动态信息 |
| 传输 | 可靠传输 | 通过网络将感知到的各种信息进行实时传输 |
| 应用 | 智能处理 | 利用计算机技术，及时对海量数据进行信息控制，真正达到人与物、物与物的沟通 |

〔C2·P6〕

三个环节与三层体系架构一一对应（感知层—网络层—应用层），第三环节课件用的词是"处理"，不是"分析"。

### 2.1.3 国内外发展现状

国外四家〔C2·P7〕：

- 美国：以**物联网应用**为核心的"智慧地球"计划（2018），核心是 3I——物联化（Instrumented）、互联化（Interconnected）、智能化（Intelligent）〔标红 C2·P7〕；
- 欧盟：十四点行动计划，涵盖标准化、研究项目、试点工程、管理机制和国际对话，并明确政府要加强对物联网的管理、统一标准制定；
- 日本：U-Japan 计划，力求实现人与物的互相连接，建设"人与物随时随地均可连接的泛在网络社会"；
- 韩国：IT839 战略与 U-Korea 战略，把泛在**物联网** USN 作为基础建设之一，并确定为经济新增长点〔标红 C2·P7〕。

国内四条〔C2·P8〕：应用领域加速发展，在民生领域试点示范与规模应用；生态体系逐渐形成，已有元器件、设备、芯片、运营、软件、服务等较完整的产业链；产业集群优势不断突显，产业发展以物联网应用平台为先导；整体应用尚未普及，高端传感器、智能硬件和核心芯片与发达国家仍存在差距，网络与信息安全存在较多隐患。

> 3I 的顺序与三层架构同构：先物联（感知）、再互联（网络）、再智能（应用）。三条正好对应三层，顺序本身有内在理由。

### 2.1.4 三层体系架构

![图 2-1 物联网三层体系架构：感知层—网络层—应用层（课件 C2·P9）](assets/figs/c2_iot_3layer.jpg)

*图 2-1 物联网三层体系架构：感知层—网络层—应用层（课件 C2·P9）*

三层即**感知层**、**网络层**、**应用层**〔标红 C2·P16〕。

（1）感知层：五官与皮肤，负责采集与识别

感知层是三层中最基础、也最为核心的一层：通过传感器对物质属性、行为态势、环境状态等各类信息进行大规模的、分布式的获取与状态辨识，采用协同处理的方式，针对具体感知任务对多种感知信息进行在线计算与控制并做出反馈〔C2·P10〕。

这一层主要由**两类设备**构成〔标红 C2·P10〕：一是各类传感器，如温度、湿度传感器、摄像头，负责"感知"；二是识别设备，如二维码、RFID 标签和读写器，负责给物体"贴标签"以便识别。

传感器按三个维度分类〔标红 C2·P11〕：

| 分类维度 | 举例 |
| --- | --- |
| 按**原理**分 | **电阻式**、**电容式**、**光栅式**、**超声波**、**激光**、**压电式** |
| 按**被测量**分 | **温度**、**湿度**、**振动**、**压力**、**力矩** |
| 按**输出信号**分 | **数字**、**模拟** |

**智能传感器**在工业中的典型应用包括视觉传感器用于车身检测、力矩传感器用于机器人、红外传感器用于工厂环境检测〔标红 C2·P12〕。

（2）网络层：神经网络与信息高速公路，负责传输与互通

网络层是整个体系架构的**中枢**，起**承上启下**的作用：解决感知层在一定范围、一定时间内所获得数据的传输问题，通常以解决长距离传输问题为主，数据可通过企业内部网、通信网、互联网、各类专用通用网、小型局域网等传输交换〔标红 C2·P13〕。

典型链路是：传感器 →（ZigBee 或 LoRa 这类低功耗局域网技术）→ 网关 →（4G/5G 或光纤等广域网技术）→ 云平台，即利用各种**有线**和**无线**网络技术构建传输通道〔标红 C2·P13〕。

> 网络层的"分层"体现在一句话里：网络层不关心数据具体代表什么，只确保数据能准确、高效地送达〔C2·P13〕。业务语义归应用层，正因为网络层不管语义，异构设备才可能互联。

（3）应用层：大脑，负责处理与决策

应用层位于三层的最顶层，主要解决信息处理、人机交互等问题，通过对数据的分析处理为用户提供丰富特定的服务。其功能包括两个方面：**数据**与**应用**——先完成数据的管理与处理，再让数据与应用相结合才产生价值〔标红 C2·P15〕。

两个关键部分〔标红 C2·P15〕：一是**物联网应用基础设施**，如支撑海量数据处理的云计算平台、大数据分析平台；二是**行业应用服务**本身，如智慧农业灌溉系统，以及智能家居、智慧交通、智慧医疗等。

> 把三层想成人体：感知层是五官与皮肤（采集），网络层是神经网络（传导），应用层是大脑（决策）。课件 P10/P13/P15 的比喻就是这三个词。

### 2.1.5 四大关键技术

（1）**传感器技术**〔标红 C2·P18〕

传感器是物联网针对自身内部及外部环境进行感知的装置系统，不仅负责感知，还能辅助实现数据的分析和传输；技术趋势是由传统传感器逐渐转变为嵌入式 Web 传感器，趋于智能化〔C2·P18〕。

无线传感器网络（WSN）通过微型传感器节点在检测区中的布局规划构成，利用无线通信技术建立一个集结化的网络结构〔C2·P18〕。其主要发展方向包括测试技术与网络化测控、传感器网络组织结构与底层协议、传感器自我检测及控制〔C2·P18〕。

（2）**云计算技术**〔标红 C2·P19〕

云计算通过远程服务器或非本地的其他服务器为用户提供数据的计算、存储服务，能实现大量数据的并行计算与弹性增长资源存储；它把海量程序分解为子程序，由多台服务器高效处理，可在很短时间内达到与超级计算机类似的效率〔C2·P19〕。物联网中的**传感设备**会不断收集数据，这些数据的存储与处理正是靠云计算完成的〔标红 C2·P19〕。

（3）**无线传感技术**〔标红 C2·P20〕

无线传感器网络是集稳定性、安全性、高效性于一身的自组织无线网络信息系统，能实现分布式的信息收集、处理与共享〔C2·P20〕。各节点处于协同运行状态，对监控区域的所有点位、所有时间实现"感知—收集—处理—传输"，再利用网关与公用网络连接，最后把信息传给监测人员〔C2·P20〕。其数据传输技术通常包括无线局域网技术（WLAN）、无载波通信技术、紫蜂协议（ZigBee）技术〔C2·P20〕。

（4）**安全与隐私技术**〔标红 C2·P21〕

物联网中一些特殊实物可能涉及商业机密或个人隐私，因此必须保证这些隐私不被泄漏。几乎所有的标签标识或识别技术都能实现远程扫描，标签又可依阅读器指令把信息传给阅读器，所以涉及机密或隐私的实物信息在标签上必须具有较高的安全性〔C2·P21〕。此外还要保障终端安全管理与感知节点的物理安全性，包括用户卡安全、设备软硬件安全，避免异常移动所导致的安全问题〔C2·P21〕。

> 【补充】除"可被远程扫描"这一条出自 P21 外，还有两点常被用来说明物联网为何比互联网更难防护：传感节点多为无人值守，被拆被改往往无人察觉；节点数量大且数据分散，逐点排查代价极高。这两条是补充说明，不属于课件原文。

### 2.1.6 典型应用与技术展望

| 应用 | 要点 |
| --- | --- |
| 智能电网 | 需效率非常高的**网络传输通信技术**，通过**传感技术**整合分析、辅助**电力运输**；可监控各**用电节点**的用电状况，实现**电网客户用电**的动态化监控〔标红 C2·P22〕 |
| 智能物流 | 物联网贯穿采购、生产、销售各环节，进一步控制企业生产成本与货物运输成本〔C2·P23〕 |
| 智慧农业 | 智能大棚是典型应用：运用多种传感器具体操作，简化生产工序、减少工作量，产量显著增长〔C2·P24〕 |
| 智能交通 | 智能停车引导与智能交通预警：摄像头采集画面与信息传至后台分析，结果推送到用户手机或广播〔C2·P25〕 |
| 环境监测 | 多节点自组网，某些节点不可用后其他节点可自行挑选路径形成全新网络；采集的数据可云托管，兼顾安全与分析共享〔C2·P26〕 |

**物联网技术展望**〔标红 C2·P27〕：NB-IoT、5G、人工智能、云计算、大数据、区块链、边缘计算等一系列新技术将持续注入物联网领域，助力"物联网+行业应用"落地，在工业、能源、交通、医疗、新零售等领域不断普及，并催生智能门锁、智能音箱、无人机等新单品；未来几年这些技术与物联网的关系将被理顺，进而构建出新的、泛在的智能 ICT 基础设施〔C2·P27〕。

## 2.2 网络通信技术

### 2.2.1 定位：新基建与两类连接技术

工业互联网属于**新基建**，是**七大板块之一**，也是从传统消费互联网（To C）向产业互联网（To B）转型的重要方向。**网络通信技术**是产业发展的重要推动力量，是工业互联网的**基础设施**，是连接先进信息技术（物联网、大数据、云计算、人工智能等）与工业全要素之间的桥梁〔标红 C2·P31〕。

新基建包括 5G 基站建设、特高压、城际高速铁路和城市轨道交通、新能源汽车充电桩、大数据中心、人工智能、工业互联网七大领域〔C2·P31〕。

**工业互联网连接技术**包括**有线**连接与**无线**通信两大类别；其中无线通信技术因部署简单、功能强大、使用便捷、组网灵活、覆盖区域大而在工业互联网中广泛使用，特别是 5G、TSN、LoRa 等新技术的导入所引发的技术变革〔标红 C2·P32〕。

不同场景的通信要求〔C2·P33〕：

| 场景 | 要求 | 对应技术 |
| --- | --- | --- |
| 自动驾驶 | 低时延 | 5G 的 uRLLC |
| 远程医疗 | 大带宽 | 5G 的 eMBB |
| 低速率、大容量、远距离 | 广覆盖低功耗 | 各种 LPWAN 制式：LoRa、NB-IoT、Chirp-IoT 等 |
| 对 MESH 组网要求较高 | 自组网 | BLE / ZigBee |

> 三张 5G 名片要分清：eMBB 管大带宽（远程医疗），uRLLC 管低时延高可靠（自动驾驶），mMTC 管海量连接。课件这一页只用了前两张加 LPWAN 的"大容量"。

### 2.2.2 有线：现场总线与工业以太网

**工业控制网络**主要分为**现场总线**和**工业以太网**两大技术体系，以实现现场控制为主〔标红 C2·P34〕。

（1）工业总线的三种基本类型

工业总线可分为传感器级总线、设备级总线和现场总线三类〔C2·P35〕：

| 类型 | 层次 | 连接的设备 |
| --- | --- | --- |
| **传感器级**总线 | **较低层次的工业网络** | 传感器、行程开关、继电器、接触器和阀门定位器这类工业设备 |
| **设备级**总线 | **较低层次的工业网络**（与传感器级相同） | 同上，课件原文如此并列 |
| **现场总线** | **较高层次的工业网络** | 完成一些过程控制器或现场仪表之间的通信 |

〔标红 C2·P35〕

（2）现场总线的定义与本质

**现场总线**是一种应用于生产现场，在现场设备之间、现场设备和控制装置之间实行双向、串行、多结点的数字通信技术〔标红 C2·P35〕；它也常被表述为一种数字式、多分支结构和双向传输的通信网络，连接了智能现场设备和自动化系统〔C2·P34〕。

课件的"本质"六点〔C2·P36〕：

| 本质 | 含义 |
| --- | --- |
| 现场通信网络 | 用于过程自动化和制造自动化的现场设备或现场仪表互连的现场通信网络 |
| 现场设备互联 | 依据实际需要，使用不同的传输介质把不同的现场设备或者现场仪表相互关联 |
| 互操作性 | 不同厂商的现场设备能够在同一条总线上互换、互相读懂对方的数据〔阐释〕 |
| 分散功能块 | FCS 废弃了 DCS 的输入/输出单元和控制站，把 DCS 控制站的功能块分散地分配给现场仪表，从而构成虚拟控制站，彻底地实现了分散控制 |
| 通信线供电 | 允许现场仪表直接从通信线上摄取能量，为本质安全环境提供低功耗的现场仪表，配套还有安全栅 |
| 开放式互联网络 | 现场总线为开放式互联网络，既可以与同层网络互联，也可与不同层网络互联，还可以实现网络数据库的共享 |

> 六点里最常被追问的是"分散功能块"和"通信线供电"。前者是控制权的下放：DCS 把控制逻辑集中在一台控制站里，FCS 把它切成功能块，塞进每一台现场仪表，于是"控制站"变成一层虚的概念。后者是把供电也做进通信线，仪表在危险区（本质安全环境）里无需另拉电源，配套用安全栅限能，避免电火花点燃可燃气体。
>
> "互操作性"的实际意义是解除厂商锁定：一条总线上可以混装不同厂家的仪表，检修时换谁家的都能用。

（3）工业以太网与四种主流协议

以太网本是计算机局域网（LAN）技术；**工业以太网**是一种专为工业环境设计的网络通信技术，基于标准以太网技术，但针对工业应用进行了优化。**主流四种**工业以太网协议为 Modbus TCP/IP、EtherCAT、EtherNet/IP 和 Profinet〔标红 C2·P37〕。

| 协议 | 推出情况 | 课件给的特点 |
| --- | --- | --- |
| Modbus TCP/IP | 首个推出的工业以太网协议 | 本质是传统 Modbus 通信在以太网传输层协议中"压缩"，用于在控制设备之间传输离散数据 |
| EtherNet/IP | 最初于 2000 年推出 | 唯一一个完全基于以太网标准、并使用标准以太网物理层、数据链路层、网络层和传输层的工业以太网协议；采用标准以太网交换，可支持无限数量的节点 |
| EtherCAT | 于 2003 年推出 | 关键要素是所有联网从机都能从数据包中仅提取所需的相关信息，并在向下游传输时把数据插入帧中——通常称为"飞速"通信 |
| Profinet | 西门子与 Profibus 用户组织的成员公司共同开发 | 利用集成至设备中的特殊交换机，本质上把 Profibus I/O 控制器通信扩展至以太网 |

〔C2·P37〕

> "飞速"（on-the-fly）指的是报文在从站之间不停留、边传边读写，而不是泛泛地说"速度特别快"。

### 2.2.3 无线通信：LTE / 5G / 室内定位 / LPWAN

无线通信技术发展迅猛，具有有线通信技术不能取代的地位：它最初主要用于**信息采集**和**生产控制**〔标红 C2·P40〕，随后逐渐渗透到企业信息化等多个环节；随着工业互联网发展，工厂与厂外设备、传感器之间的通信需求大增，移动通信网络因广覆盖、高速率、可靠性高和产业链成熟，越来越多地用于工业生产。

（1）**LTE**

**LTE**（Long-Term Evolution，长期演进）是一种高速、低延迟的 **4G 无线通信技术**，广泛用于智能手机、平板和物联网设备；它是全球唯一主流的 4G 标准，200 个国家和地区的运营商提供服务，可实现网络无缝漫游。LTE 用较少的基站就能覆盖更广区域，单站覆盖可达十几公里甚至几十公里，具有**时延小**、**可靠性高**的特点，满足**工业场景中高速数据传输要求**〔标红 C2·P42〕。以 LTE 为代表的移动通信网络，可满足工业互联网**工厂外网络**普遍覆盖和高速传输的需求，实现 IT 系统与互联网的融合、企业专网与互联网的融合〔标红 C2·P42〕。

（2）5G

5G（5th Generation Mobile Communication Technology）是具有**高速率**、**低时延**和**大连接**特点的新一代宽带移动通信技术，5G 通讯设施是实现**人机物互联**的网络基础设施〔标红 C2·P44〕。5G 网络是控制和转发分离的网络：转发面专注于业务数据的高效路由转发，控制面采用逻辑集中的方式，实现统一的策略控制、灵活的流量调度和连接管理〔C2·P44〕。

对工业互联网，5G 提供**更可靠、更开放、按需定制**的网络〔标红 C2·P44〕，更好地支撑**大流量业务**，如虚拟工厂和高清视频远程维护〔标红 C2·P44〕；还支持工厂内、外的大量设备监控，如各类设备的远程监控和控制、无线视频监控的远程控制、远程监测并上报环境参数与控制机械的数据〔C2·P44〕。5G 最大的应用之一是大规模设备通信，例如自动驾驶汽车、元宇宙硬件、VR 与**智能工厂**〔标红 C2·P43〕。

（3）室内定位

室内定位是指在室内环境中实现物体或人的**位置定位**；未来 50% 以上的信息都与**位置数据**相关，采集位置数据就要依赖定位技术〔标红 C2·P45〕。常用技术有 Wi-Fi、RFID、ZigBee、红外线、蓝牙和 UWB 超宽带等〔C2·P45〕：

| 技术 | 定位精度（米） | 覆盖范围 | 保密性 | 穿透性 | 抗扰性 |
| --- | --- | --- | --- | --- | --- |
| RFID | 10 ~ 100 | 小 | 高 | 差 | 好 |
| WiFi | 3 ~ 15 | 大 | 差 | 差 | 差 |
| 蓝牙 Beacon | 1 ~ 5 | 大 | 一般 | 好 | 差 |
| ZigBee | 3 ~ 10 | 大 | 一般 | 好 | 差 |
| UWB（超宽带） | 0.1 ~ 0.5 | 小 | 高 | 差 | 好 |

〔C2·P45〕

精度最高的是 UWB（0.1 ~ 0.5 米），最差的是 RFID（10 ~ 100 米）；覆盖范围标"小"的有两项——RFID 与 UWB。保密性"高"、抗扰性"好"的也正好是这两项，而穿透性"好"的只有蓝牙与 ZigBee。

（4）LPWAN

**LPWAN**（**低功耗广域物联网**，Low Power Wide Area Network）以**低功耗**、**广覆盖**和**大连接能力**为核心〔标红 C2·P48〕，适用于大规模物联网设备的远程通信。工业互联网环境存在大量传感器、阀门、过程控制变量等低速信号需要采集与处理，常用到 LPWAN〔C2·P48〕。

| 类别 | 频谱 | 信道带宽 | 通信速率 | 容量 | 覆盖范围 | 模组成本 | 续航 | 建网方式 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| LTE-Cat1 | 授权频谱 | < 18 MHz | < 5 Mbps | 一般 | 较大 | $5~10 | 2~3 年 | 蜂窝公网 |
| LTE-eMTC | 授权频谱 | 1.4 MHz | < 1 Mbps | 较大 | 大 | $5~10 | 5 年 | 蜂窝公网 |
| **NB-IoT** | 授权频谱 | 180 kHz | < 250 kbps | 大 | 大 | < $5 | 5 年 | 蜂窝公网 |
| **LoRa** | 非授权频谱 | 125 kHz | < 50 kbps | 大 | 大 | < $5 | 10 年 | 自组网络 |
| Chirp-IoT | 非授权频谱 | 125 kHz | < 50 kbps | 大 | 大 | < $5 | 10 年 | 自组网络 |
| SigFox | 非授权频谱 | 100 Hz | < 100 bps | 大 | 大 | < $5 | 10 年 | 自组网络 |

〔标红 C2·P48〕

> NB-IoT 与 LoRa 的差别不在速率，而在频谱是否授权、以及建网方式（蜂窝公网 / 自组网）；表里三组数字值得留意：NB-IoT 授权 180 kHz、5 年；LoRa 非授权 125 kHz、10 年。容量一列从"一般"到"大"逐级抬升，LTE-Cat1 主打速率、SigFox 主打极窄带。

## 2.3 云计算技术

### 2.3.1 定义与"云—大"关系

**云计算**（**Cloud Computing**）是分布式计算的一种，指通过网络"云"将巨大的**数据计算处理程序**分解成无数个**小程序**，然后通过多部服务器组成的系统处理和分析这些小**程序**，得到结果并返回给用户〔标红 C2·P51〕。

**云计算**是大数据的来源和支撑，**大数据**是云计算的灵魂和发展方向〔标红 C2·P52〕。

> "来源和支撑"说的是算力与存储托着数据，"灵魂和发展方向"说的是数据反过来给云提出需求——两者互为前提，不是单向的上下游。

### 2.3.2 三种服务模式：IaaS / PaaS / SaaS

按服务类型大致分三类：SaaS（软件即服务）、PaaS（平台即服务）、IaaS（基础设施即服务）〔C2·P53〕。

| 模式 | 定义 | 用户实际拿到的东西 | 自主权 |
| --- | --- | --- | --- |
| **IaaS/基础设施即服务** | 将硬件设备等基础资源封装成服务供用户使用；用户相当于在使用裸机和磁盘；由公众共享，资源使用效率更高 | 裸机与磁盘，操作系统及以上全部自装；允许动态申请或释放节点、按使用量计费 | 最高 |
| **PaaS/平台服务** | 对资源的抽象层次更进一步，提供用户应用程序的运行环境；自身负责资源的动态扩展和容错管理，用户不必过多考虑节点间的配合 | 应用程序的运行环境，但必须使用特定的编程环境并遵照特定的编程模型 | 降低 |
| **SaaS/软件服务** | 针对性更强，将某些特定应用软件功能封装成服务 | 只提供某些专门用途的服务供应用调用 | 最低 |

〔标红 C2·P54〕

> 三者的边界就在"谁负责运行用户自定义程序"这句话上。课件 P54 的原话是：SaaS 既不像 PaaS 一样提供计算或存储资源类型的服务，也不像 IaaS 一样提供运行用户自定义应用程序的环境〔C2·P54〕——也就是说，"运行用户自定义应用程序的环境"属于 IaaS，PaaS 给的是"应用程序的运行环境"。差别在于：IaaS 只到裸机加磁盘，操作系统、中间件、运行环境都算用户自己的活；PaaS 把运行环境也包了，代价是用户被限定在它支持的编程环境与编程模型里。
>
> 一句话对照：IaaS 给机器，PaaS 给环境，SaaS 给功能。抽象层次与服务商管得越多，用户自主权越小。

### 2.3.3 七大特点

云计算**七大特点**〔标红 C2·P56〕：

1. 资源池化计费："云"是一个庞大的资源池，用户按需购买，像自来水、电和煤气那样计费；
2. 规模巨大："云"具有相当的规模，谷歌云计算已拥有上百万台服务器；
3. 不针对特定应用：在"云"的支撑下可以构造出千变万化的应用；
4. 动态伸缩："云"的规模可以动态伸缩，满足应用和用户规模增长的需要；
5. 高可靠性："云"使用数据多副本容错、计算节点同构可互换等措施来保障服务的高可靠性；
6. 极其廉价："云"的特殊容错措施使得可以采用极其廉价的节点来构成云，而"云"的自动化管理又使数据中心管理成本降低；
7. 虚拟化（位置透明）：应用在"云"中某处运行，用户无须了解应用的具体位置，一台计算机、PAD 或手机就能通过网络服务获取能力超强的服务。

> 课件这一页排了 8 个文本框，其中"特殊容错可采用廉价节点"与"自动化管理降低数据中心成本"合起来才是第 6 条"极其廉价"，而"用户无须了解应用位置"独立成第 7 条，名目是虚拟化（位置透明）。照文本框数数会多出一条。

### 2.3.4 发展现状

云计算是多种技术混合演进的结果，成熟度较高，又有大公司推动，发展极为迅速：谷歌、亚马逊和微软等大公司是云计算的先行者，云计算领域众多成功公司还包括 Facebook、YouTube、MySpace 等。近年一个显著变化是以**阿里云**、云创存储等为代表的中国云计算迅速崛起，例如阿里巴巴已在北京、杭州、青岛、香港、深圳、硅谷拥有云计算数据中心，并正在德国、新加坡和日本建设数据中心〔标红 C2·P58〕。

### 2.3.5 五大优势

| 优势 | 描述 |
| --- | --- |
| 按需自助服务 | 用户可根据自己的需求购买云计算服务 |
| 广泛的网络接入 | 任何地点、任何时间只要有网络即可 |
| 资源池化 | 可随意加减资源，最大特点是屏蔽硬件差异（品牌、型号） |
| 快速弹性伸缩 | 可快速根据需求增减服务 |
| 可计量服务 | 用技术和其他手段实现单位的统一 |

〔C2·P60〕

**云计算优势**的本质是：技术特征和规模效应带来的**压倒性的性能/价格比优势**〔标红 C2·P61〕。全球企业**IT开销**分三部分：**硬件开销**、**能耗**和**管理成本**；使用**云计算**后，大型数据中心的网络、存储和管理成本相比中型至少可以降低 5～7 倍〔标红 C2·P61〕——课件以**谷歌数据中心**为例：2024 年超过 30 个，覆盖北美、欧洲、亚洲和南美等地区〔标红 C2·P61〕。

### 2.3.6 云计算与工业互联网

**云计算与工业互联网**〔标红 C2·P57〕的关系有三层：其一，云计算是推动工业互联网发展的关键技术力量，如果没有云计算，以及在云计算平台上所运行的大数据技术，工业互联网就不会存在；其二，使用工业云平台能够支撑企业智能制造、云制造、协同制造三类制造，逐步促进企业的能力上云、业务上云、设备上云和管理上云，帮助企业实现数字化转型；其三，通过云计算的应用，可以让更多企业员工与管理者使用工业互联网，也让开发者有更大空间去设计更好的应用。

## 2.4 工业大数据技术

### 2.4.1 定义与核心技术

**工业大数据技术**是指在工业领域中，围绕典型智能制造模式，从客户需求到销售、订单、计划、研发、设计、工艺、制造、采购、供应、库存、发货和交付、售后服务、运维、报废或回收再制造等整个产品全生命周期各个环节所产生的各类数据及相关技术和应用的总称〔标红 C2·P64〕。

工业大数据的**核心技术**包括**采集技术**、**管理技术**、**分析技术**与**平台技术**〔标红 C2·P65〕。

### 2.4.2 三类主体来源

工业大数据的**来源**可分为三类〔标红 C2·P66〕：

| 类别 | 内容 | 具体系统/数据 | 特点 |
| --- | --- | --- | --- |
| **企业信息化数据** | 企业运营管理相关的业务数据 | ERP、PLM、SCM、CRM 等 | 工业企业传统意义上的**数据资产**〔标红 C2·P67〕 |
| **工业物联网数据** | 制造过程数据：装备、物料及产品加工过程的工况状态参数、环境参数等生产情况数据 | 通过 **MES** 系统实时传递 | 智能装备大量应用下，此类数据量增长最快 |
| **企业外部数据** | 外部跨界数据：产品售出后的使用、运营情况数据，以及客户名单、供应商名单、外部互联网数据 | — | 跨界、外部 |

〔标红 C2·P69〕

制造业 10 大系统集成〔标红 C2·P67〕：

| 缩写 | 全称 | 缩写 | 全称 |
| --- | --- | --- | --- |
| **MES** | 制造执行系统 | APS | 高级计划和排程 |
| ERP | 企业资源规划 | **SCADA** | 监控控制与数据获取 |
| SCM | 供应链管理 | PLM | 产品生命周期管理 |
| WMS | 仓库管理系统 | QMS | 质量管理系统 |
| CRM | 客户关系管理 | EAM | 企业资产管理 |

> 课件 P68 另有一张图只列六项，把 SCM/PLM/CRM 的位置换成了 BPM（流程管理系统）与 TPM（设备管理系统），两页清单并不完全一致。

### 2.4.3 四类关键技术

（1）**采集技术**

工业大数据的**采集方法**有三条路径〔标红 C2·P71〕：主要通过 PLC、SCADA、DCS 等系统**从机器设备实时采集数据**；也可通过**数据交换接口**从实时数据库等系统以透传或批量同步的方式获取**物联网数据**；同时还需要从业务系统的关系型数据库、文件系统中采集所需的结构化与非结构化业务数据。其中 DCS（分布式控制系统）、PLC（可编程逻辑控制器）、SCADA（监控与数据采集系统）是工业自动化中常见的三种技术〔C2·P71〕。

智能制造中，**数据采集**是生产中最实际、最高频的需求，也是工业 4.0 的先决条件〔标红 C2·P72〕。

（2）**存储与管理技术**

**多源异构数据**是指数据源不同、数据结构或类型不同的数据集合〔标红 C2·P73〕。

**多源异构数据管理**需要突破的是针对不同类型数据的存储与查询技术，并在充分考虑数据来源与结构随时间推移不断增加与变化的情况下，研究如何形成可扩展的一体化管理系统；还要针对工业数据在不同阶段、不同流程呈现多种模态（关系、图、键值、时序、非结构化）的特点，研制不同的数据管理引擎〔标红 C2·P74〕。

**多模态数据集成技术**的目的是把多模态数据有机地结合在一起，发挥单一模态无法挖掘出的价值；它关心数据之间是否存在某些内在联系，从而使这些数据能被协同地用于描述或解释某些工业制造或设备使用的现象〔标红 C2·P75〕。

（3）分析技术：三类

| 分析技术 | 数据来源 | 能做什么 |
| --- | --- | --- |
| **时序模式分析技术** | 生产加工、动力能源、运输交通、信息保障、运维管控设备上加装的温度、振动、压力、位移、重量等传感器持续产生的海量时序数据〔C2·P76〕 | 设备故障预警和诊断、利用率分析、能耗优化、生产监控 |
| **工业知识图谱技术** | 工厂中的人、设备、材料、工艺、环境、测量及故障、经验、因果关系；维修工单、工艺流程文件、故障记录等非结构化日志文本 | 构建机器可理解、可推理的结构化知识网络；做事件实体与类型提取（故障类型抽取）、事件线索抽取（故障现象、征兆、排查路线、结果分析），沉淀专家知识库（故障排查、运维检修、设备操作）〔C2·P77〕 |
| **多源数据融合分析技术** | **企业内部**信息系统（CRM、MES、ERP、SEM）的生产数据、管理数据、销售数据，以及**企业外部**的物流数据、行业数据 | 价格预测、精准销售、产品追溯、质量管控；提高生产加工能力、质量监控能力、企业运营能力、风险感知能力〔C2·P78〕 |

〔标红 C2·P76–P79〕

传感器数据的很多重要信息隐藏在时序模式结构中，只有挖掘出背后的结构模式，才能构建效果稳定的数据模型〔C2·P76〕——这是时序分析为什么排在第一类的理由。多源数据分析的算法族包括统计分析算法、深度学习算法、回归算法、分类算法、聚类算法、关联规则等〔C2·P79〕。

（4）前沿技术趋势

深度学习、工业知识图谱、虚拟现实等前沿技术已经在互联网环境得到广泛应用，但这些技术如何在工业场景中发挥价值，还需要进一步探索〔C2·P81〕。具体方向有两条：在深度学习应用方面，利用深度学习算法在工业场景中开展图像和视频处理将成为重要发展方向；在**工业知识图谱**方面，如何在工业生产过程中提取工业语义关键信息并关联形成具备专业特点的工业知识图谱，是下一步探索的重点〔标红 C2·P82〕。

### 2.4.5 核心价值与典型应用场景

核心价值五条〔C2·P84〕：工业大数据是新工业革命的**基础动力**；**提升制造智能化水平**，推动中国工业升级；**支持工业互联网发展**，促进中国工业转型；助力**中国制造**弯道取直；以及在**智能制造中**的应用价值〔标红 C2·P84〕。

典型应用场景五个〔C2·P85〕：智能化设计、智能化生产、网络化协同制造、智能化服务、个性化定制。

> 这五个场景与平台应用的四个新模式名称相近，但出处不同。第 6 章 P23 讲平台与工业应用程序带来的应用变化时，用的是"覆盖智能化生产、网络化协同、个性化定制、服务化延伸等方面"〔C6·P23〕——那里没有"智能化设计"，把"智能化服务"换成了"服务化延伸"。两处各自成立，套改会出错。

## 2.5 信息安全技术

### 2.5.1 形势

工业互联网以连接为本质、以人才为驱动、以智能科技为技术支撑，除此以外还需要**以安全为保障**〔标红 C2·P88〕。近年来以工业互联网为攻击目标的网络安全事件层出不穷，**工业互联网时代**的到来也从侧面预示着**工业病毒时代**的到来〔标红 C2·P88〕。

2025 年：网络安全漏洞总数达 48482 条，同比增长 21.1%；其中**工控系统漏洞** 864 条，同比上升 13.2%〔标红 C2·P88〕。针对工业控制系统的网络攻击集中在电力、化工、石油、铁路、新能源、核应用等关键领域，关系到国家经济命脉的产业行业的信息安全〔C2·P88〕。

### 2.5.2 风险构成：五类

**风险构成**包括**设备安全**、**网络安全**、**数据安全**、**控制安全**、**管理安全**五类〔标红 C2·P89〕：

| 风险类型 | 课件描述 |
| --- | --- |
| **设备安全** | 设备层的信息安全风险得不到治理，极可能会影响整个工业互联网的正常运行 |
| **网络安全** | 工业企业现阶段的网络建设模式使网络拓扑结构越发复杂、变化多端，导致传统静态防护系统失效 |
| **数据安全** | 企业信息数据处理更加便捷，并逐步实现由内向外的双向共享流动，所涉及的数据处理环节增多，某种程度上产生了新风险 |
| **控制安全** | 工业互联网结构下信息技术与运营技术高度融合，在很大程度上破坏了传统安全可信的控制环境 |
| **管理安全** | 当前阶段的互联网技术应用仍未完全成熟，很多情况下依旧需要人的管理维护介入 |

> 课件这一页是五类，含"管理安全"；第 6 章的安全体系框架则是设备、控制、网络、应用、数据五维〔C6·P14〕。两处的第五项不是同一个词。

### 2.5.3 影响因素：人员与技术

| 因素 | 具体表现 |
| --- | --- |
| 人员 | 工业互联网的发展与应用对企业管理结构形成较大挑战；很多企业对工业互联网信息安全的认知尚未达到相当高度，相关长效机制暂未形成、没有融入整个文化体系，导致员工主动意识薄弱，进而增加信息安全风险 |
| 技术 | 受制于技术水平，很多企业工控网络系统的安全防护等级较低，多数情况下只能被动应对，存在一定的滞后性；同时现代化生产对工控管理的要求越来越高，涉及的理论、技术不断增多并日益复杂化 |

〔C2·P90〕

### 2.5.4 三类信息安全技术

工业互联网**信息安全技术**主要有三类〔标红 C2·P91〕：

| 技术 | 课件描述 |
| --- | --- |
| 工业防火墙技术 | 在原 IT 防火墙访问控制功能基础上的加强版，能够对现场网络通讯协议进行剖析，限制非法访问 |
| 入侵检测技术 | 现阶段可以大规模应用于工业互联网领域的入侵检测技术主要包括机器学习、数据挖掘等检测方法，并且新方法新技术更新较快 |
| 新型入侵检测技术 | 三类方法：特征选择技术；图像感知哈希特征提取技术；实验数据集研究方法 |

〔C2·P91〕

> 工业防火墙与 IT 防火墙的分界就在"对现场网络通讯协议进行剖析"这一句：它要读懂 Modbus、Profinet 这类工业协议的语义，而不只是看 IP 和端口。【补充】另一半差别在处置方式——工业防火墙的阻断动作会直接停掉产线，因此策略上比 IT 防火墙保守得多。

## 本章小结

- 物联网是物与网络的结合，本质仍是互联网；特点是全面感知、可靠传输、智能处理。
- 国外四家：美国"智慧地球"3I、欧盟十四点行动计划、日本 U-Japan、韩国 IT839 与 U-Korea；国内四条为应用、生态、集群与短板。
- 三层架构：感知层（传感器＋识别设备，最基础最核心）、网络层（中枢，承上启下）、应用层（数据与应用，应用基础设施＋行业应用服务）。
- 四大关键技术：传感器技术、云计算技术、无线传感技术、安全与隐私技术。
- 五类应用：智能电网、智能物流、智慧农业、智能交通、环境监测。
- 工业互联网是新基建七大板块之一；连接技术分有线与无线两类；场景匹配：uRLLC—自动驾驶、eMBB—远程医疗、LPWAN—低速率远距离、BLE/ZigBee—MESH。
- 工业控制网络分现场总线与工业以太网；工业总线三类型为传感器级、设备级、现场总线。
- 现场总线本质六点：现场通信网络、现场设备互联、互操作性、分散功能块、通信线供电、开放式互联网络。
- 工业以太网四协议：Modbus TCP/IP、EtherNet/IP（2000）、EtherCAT（2003）、Profinet。
- LTE：4G 长期演进，时延小、可靠性高，服务工厂外网络。5G：高速率、低时延、大连接，控制与转发分离。
- 室内定位：UWB 精度最高（0.1~0.5 米），RFID 最低（10~100 米）；覆盖标"小"的是 RFID 与 UWB；未来 50% 以上信息与位置数据相关。
- LPWAN：NB-IoT（授权，180 kHz，5 年，蜂窝公网）、LoRa（非授权，125 kHz，10 年，自组网）、Chirp-IoT、SigFox（100 Hz）。
- 云计算是分布式计算的一种；三种服务 IaaS（裸机磁盘）、PaaS（应用程序运行环境）、SaaS（专门用途的服务）；七大特点含资源池、规模、通用、弹性、高可靠、极其廉价、虚拟化（位置透明）。
- 发展现状：谷歌、亚马逊、微软为先行者；阿里云六地数据中心。五大优势：按需自助、广泛接入、资源池化、快速弹性、可计量；本质是压倒性的性能/价格比优势。
- 工业大数据四类核心技术：采集、管理、分析、平台；三类来源：企业信息化数据、工业物联网数据（增长最快）、外部跨界数据。
- 分析技术三类：时序模式分析、工业知识图谱、多源数据融合分析；前沿趋势为深度学习、工业知识图谱、虚拟现实。
- 技术架构四层：采集交换、集成处理、建模分析、决策控制；五场景：智能化设计、智能化生产、网络化协同制造、智能化服务、个性化定制。
- 安全风险五类：设备、网络、数据、控制、管理；影响因素为人员与技术；三类技术：工业防火墙、入侵检测、新型入侵检测。
