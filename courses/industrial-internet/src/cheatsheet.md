## 4 易混对比（选择题的正确答案都在这张表里）

| 易混项 | 正确区分 |
| --- | --- |
| 互联网 vs 万维网 | 互联网是**网络**；万维网（WWW）是建立在互联网上的**信息服务系统** |
| 物联网 vs 工业物联网 | IIoT 是 IoT 的**子集**，偏**生产/高价值资产/安全**；又是工业互联网的**同义词 + 包含关系** |
| 工业互联网 vs 智能制造 | 前者是**依托基础**（偏工业服务、企业上云）；后者是**最终目标**（偏工业制造、价值链智能化） |
| 1.0 vs 2.0 三核心 | 1.0：网络/数据/安全；2.0：网络/**平台**/安全（平台替代数据） |
| 平台 3 层 vs 4 层 | 第 3 章功能视图 3 层；第 5 章功能架构 4 层（多 IaaS） |
| 3 体系 vs 4 系统 | 3 体系 = 网络/平台/安全；4 系统 = 网络/**标识**/平台/安全 |
| 业务视图四层 vs 功能架构四层 | 业务视图 = 产业/商业/应用/**能力**；功能架构 = 设备/工厂/企业/产业 |
| 安全五性 vs 五维 | 五性 = 可靠性/保密性/完整性/可用性/隐私；五维 = 设备/控制/网络/应用/数据 |
| 第 2 章 vs 第 6 章风险构成 | 第 2 章 = 设备/网络/数据/控制/**管理**；第 6 章 = 设备/控制/网络/**应用**/数据 |
| 现场总线 vs 工业以太网 | 现场总线：数字/双向/多节点/串行、专用线缆；工业以太网：基于 IEEE 802.3、交换机、可与 IT 融合 |
| Modbus vs Modbus TCP | Modbus 是**协议**（可跑在 RS232/485/422 串口上）；Modbus TCP/IP 是它在**以太网传输层**上的形式 |
| EtherCAT vs EtherNet/IP | EtherCAT：**飞速**（边传边读写）；EtherNet/IP：**唯一完全基于以太网标准**、支持 TCP/UDP |
| NB-IoT vs LoRa | NB-IoT：**授权频谱 + 蜂窝公网**；LoRa：**非授权频谱 + 自组网** |
| IT 网络 vs OT 网络 | IT 管企业级业务（可打补丁重启）；OT 管车间/现场实时控制（不能停线） |
| 主动 vs 被动标识载体 | 主动自带通信与计算、可主动上报（贵、要供电）；被动靠外部读写（便宜、距离近） |
| 标识解析 vs DNS | 标识解析返回**地址 + 关联信息**，多根并存，解决跨企业数据互通；DNS 只做域名→IP |
| 原始数据层 vs 特征层 vs 决策层融合 | 越靠前**信息全但实时性差**，越靠后**实时但精度降** |
| 代码审计 vs 脆弱性检测 | 代码审计看**源代码**（白盒）；脆弱性检测看**已编译程序**（漏洞库 + 逆向） |
| 网络隔离三种 | **物理隔离、协议隔离、应用隔离** |
| 公有云 vs 私有云 | 公有云**弹性好、按需付费**；私有云**安全可控但失去弹性** |
| PaaS vs IaaS | PaaS 给**运行环境**（自主权降低）；IaaS 给**裸机/磁盘**（自主权最高） |
| 数字孪生 vs 仿真 | 数字孪生**实时同步 + 双向交互 + 全生命周期**；仿真只是离线模型 |
| PLC vs DCS vs SCADA | PLC = 单元级、循环扫描；DCS = 系统级、分散控制集中管理、同一地理位置；SCADA = 系统级、测控点分散、管理集中控制分散 |

## 5 论述题万能句（每条都能直接用）

1. **总起**：工业互联网由**网络、平台、安全**三大体系构成，网络是基础、平台是核心、安全是保障。
2. **定义**：工业互联网是**新一代信息通信技术与工业经济深度融合的新型基础设施、应用模式和工业生态**。
3. **本质**：通过开放的、全球化的工业级网络平台，把**设备、生产线、工厂、供应商、产品和客户**
   连接融合，形成**跨设备、跨系统、跨厂区、跨地区**的互联互通。
4. **平台**：工业互联网平台的本质是"**数据 + 模型 = 服务**"，边缘层是前提、IaaS 是基础、
   工业 PaaS 是核心。
5. **数据流**：数据自下而上流动（感知→网络→平台→应用），决策自上而下执行。
6. **CPS**：CPS 的本质是构建**状态感知、实时分析、科学决策、精准执行**的**数据自动流动闭环**。
7. **分层思想**：每层只关心自己的职责——网络层不关心数据代表什么，只保证准确高效送达。
8. **安全**：工业安全的核心矛盾是**信息安全与功能安全交织**——防护不能停机、不能增加时延。
9. **收尾（降本增效）**：最终都要落到**降低成本、提高效率、提升质量、保障安全**四件事上，
   这也是工业互联网"为什么值得建"的答案。
10. **案例支撑**：安贝格（99.9985%、75% 自动化、产能 8 倍/质量 40 倍）、博世洪堡（库存 −30%、
    效率 +10%）、波音 B787（自制 10%、40 多家伙伴）、航天云网（周期 −75%、成本 −50%）。
